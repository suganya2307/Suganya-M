# AI HR Recruitment Assistant

An Agentic AI application that helps HR teams screen resumes, match candidates with job descriptions, and generate relevant interview questions.

## Key Features
- Resume screening and analysis
- Candidate and job description matching
- Skill extraction
- Candidate ranking
- Interview question generation
- Recruitment FAQ support
- RAG-based document retrieval
- Memory for candidate details and previous interactions
- Agent-based tool calling

## Technologies
Agentic AI, RAG, Memory, Tool Calling, Generative AI

## Project Type
IBM Agentic AI Internship Final Project

## Objective
To develop an intelligent AI-powered recruitment assistant that automates resume analysis and supports HR teams in making efficient and informed recruitment decisions.
